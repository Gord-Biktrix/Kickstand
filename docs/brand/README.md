# Kickstand brand

Final mark from Claude Design (2026-09-08): the "K strut" — the K's stem floats and only its leg touches the
baseline, so the letter is held upright the way a kickstand holds a bike. Rounded-square tile (radius 14/64),
stroke 8/64 (= 2px at 16px), Geist 600 wordmark, letter-spacing -0.025em.

Colours: #C2410C accent · #9A3412 accent-strong · #FFF1E8 accent-soft · #171717 ink · #FAFAFA paper.

- `kickstand-icon.svg` — tile + mark, used as the app icon (`src/app/icon.svg`, `src/app/apple-icon.tsx`).
- `kickstand-mark.svg` — bare mark in currentColor, for placing on orange or dark surfaces.
- React: `src/components/logo.tsx` (`KickstandMark`, `KickstandLogo`).

Source canvases: "Kickstand Logo.dc.html" / "Kickstand Final.dc.html" (Claude Design export, kept in Downloads).
